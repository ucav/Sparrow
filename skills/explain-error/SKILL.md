# Skill: Explain Error

**Trigger:** explique cette erreur, what does this error mean, décortique ce bug, debug this

**Description:** Décortique un message d'erreur ou un backtrace et l'explique en langage clair. Identifie la cause racine et propose une solution concrète.

## Body

Quand on te donne un message d'erreur :

1. **Identifier** : quel type d'erreur ? (compilation, runtime, réseau, permissions, logique)
2. **Traduire** : explique ce que le message veut VRAIMENT dire, en français simple
3. **Cause racine** : pourquoi cette erreur se produit-elle dans ce contexte ?
4. **Solution** : propose UNE solution concrète et actionnable, avec code si pertinent
5. **Prévention** : comment éviter cette erreur à l'avenir ?

Format de réponse :
```
🔍 **Type** : [Compilation / Runtime / Réseau / ...]
📝 **Traduction** : [En français simple]
🎯 **Cause** : [Pourquoi ça arrive]
✅ **Solution** : [Code ou action précise]
🛡️ **Prévention** : [Bonne pratique]
```
