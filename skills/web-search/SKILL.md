# Skill: Web Search
**Trigger:** search the web, google this, recherche, find online
**Description:** Search the web for information using DuckDuckGo. Returns structured results with titles, URLs, and snippets.

## Body
1. Formulate a precise search query
2. Use web_search tool with the query
3. Read top 5 results
4. Synthesize findings with source links
5. If results are insufficient, refine the query and retry
