# Skill: Git Workflow

**Trigger:** commit, branch, PR, pull request, merge, rebase, git

**Description:** Clean git workflow: branches, atomic commits, descriptive PRs.

## Body
When working with git:
1. Create a branch for each feature/fix: `feature/description` or `fix/description`.
2. Make atomic commits: one logical change per commit.
3. Write descriptive commit messages: what + why, not just what.
4. Push branch and create PR with: summary, changes, testing notes.
5. Rebase on main before merging.
6. Use `sparrow checkpoint` before risky operations.
7. NEVER force-push to shared branches without coordination.
