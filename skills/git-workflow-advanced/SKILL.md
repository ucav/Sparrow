# Skill: Git Workflow Advanced
**Trigger:** git workflow, manage branches, merge, rebase, PR workflow
**Description:** Advanced Git operations — branching, merging, rebasing, PR management, conflict resolution.

## Body
1. Check current state: git status, git branch
2. For new features: git checkout -b feat/description
3. For fixes: git checkout -b fix/description
4. Commit with Conventional Commits format
5. Push and create PR: gh pr create
6. For conflicts: identify conflicting files, resolve manually, git add, git rebase --continue
7. Clean up merged branches: git branch -d feat/old-branch
