# Skill: Browser Automation
**Trigger:** browse this site, open this URL, navigate to, screenshot
**Description:** Automate browser interactions — navigate, click, type, screenshot, extract content.

## Body
1. Navigate to the target URL using browser_navigate
2. Take a snapshot to see page structure
3. Click elements by their ref ID (e.g., @e5)
4. Type into input fields by ref ID
5. Take screenshots for visual verification
6. Extract structured data from the page
