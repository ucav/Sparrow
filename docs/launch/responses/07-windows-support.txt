Yes, real Windows support. CI runs `windows-latest` for fmt / clippy /
test / build on every PR. The release pipeline ships
`sparrow-windows-x86_64.exe` as a signed-when-possible single file.

Install on Windows three ways:

  irm https://raw.githubusercontent.com/ucav/Sparrow/master/install.ps1 | iex
  scoop bucket add ucav https://github.com/ucav/scoop-bucket && scoop install sparrow
  winget install ucav.Sparrow

Two honest caveats:

  1. Code signing on Windows requires Azure Trusted Signing or an EV
     cert. I'm working on this. Until then, SmartScreen will warn on
     first run. You can verify the SHA256 against the release page.

  2. Sandboxing on Windows is reported as "unsupported" — there is no
     bwrap equivalent. I prefer that over shipping a fake sandbox.
