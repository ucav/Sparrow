# Hook tweet — 5 variants for A/B

The hook is the single highest-leverage line of the whole launch. Pick by
mood and audience, but always commit before posting — never edit a hook.

Each variant assumes the same media attached: `assets/launch/x-hook-receipt.svg`
(or a swap noted inline).

---

## Variant A — The receipt (default)

> $847 in 4 days on Claude Code.
> 11 files modified.
> Closed the laptop. Opened Rust. Built Sparrow.

*Strength:* concrete number, builder energy, no hype.
*Risk:* people ask if the number is real. It must be, or scaled-down to a
real number you can produce.

---

## Variant B — The confession

> I built a tool because I was mad at the one I was paying for.
> One binary, any model, git checkpoints, hard budget caps.
> No subscription. No cloud. Sparrow.

*Strength:* universal feeling, no number to defend.
*Risk:* slightly softer hook, may scroll past faster.

---

## Variant C — The mechanic

> `sparrow rewind --last` is the command I wish every coding agent had.
> Undoes the files. Undoes the conversation. Undoes the counter.
> Try it.
>
> [attach 5s GIF of rewind]

*Strength:* shows a verb you can't get elsewhere. Concrete.
*Risk:* needs a clean GIF — if the GIF is jank, dies.

---

## Variant D — The flex (use carefully)

> 38 LLM providers.
> One binary.
> Zero abonnement.
> Zero cloud.
> Zero telemetry.
>
> github.com/ucav/Sparrow

*Strength:* punchy, scannable.
*Risk:* sounds like a SaaS landing. Only post this if the media is strong
(use `comparison-card`).

---

## Variant E — The roast

> Claude Code costs $20/mo and locks you to one provider.
> Codex costs $20/mo and locks you to another.
> Aider is free but you also have to deal with Python.
>
> I built Sparrow. One binary. Any provider. Zero pain.

*Strength:* names competitors directly, sticks.
*Risk:* punching up at Anthropic/OpenAI invites pile-ons. Only ship if you
can sustain a 6-hour reply window.

---

## Picking guide

| If you have… | Use |
|---|---|
| A real receipt screenshot | **A** |
| Only the GIF | **C** |
| Only a still image, broad audience | **B** |
| Strong comparison card, ready to defend | **D** |
| Six hours of patience and thick skin | **E** |

When in doubt: **A**. Real number wins.

## Reposting later

If the hook flops (< 5 RT after 6 h), do NOT delete and reshoot. Wait 7
days, post a different variant with new media, no link, treat as net-new.
