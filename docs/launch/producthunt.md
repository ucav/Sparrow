## Maker first comment (paste right after launch goes live)

```
Hey hunters 👋

I built Sparrow because I closed my laptop after a $847 four-day spend
on Claude Code and realized the tool I was paying for had no answer to
the three things I needed most: pick the cheapest model that can do
the job, undo a whole run in one command, and stop spending when I say
so.

So Sparrow does exactly those three things.

It's a single Rust binary (`cargo install sparrow-cli`). It routes
between 38 providers (Ollama is the default first hop — so $0.00 runs
are normal). Every mutating step is git-checkpointed, and
`sparrow rewind --last` undoes files + conversation + counters atomically.
Hard caps per run: --max-cost-usd, --max-wall-secs, --max-tokens.

What I'd love feedback on:
- Which of the 38 providers you'd use first
- Whether the drop-in import of ~/.claude/{CLAUDE.md, agents/, commands/}
  is enough for you to switch
- The autonomy contract (supervised / trusted / autonomous + HardStops)

I'm one person, two kids, post-burnout. If you find a bug today I'll
ship the fix tonight. Promise.

github.com/ucav/Sparrow
```

## Tips that are not obvious

- PH's "Featured" decision is taken **before** noon PT. So early
  upvotes from your timezone (if you're in EU, that's 9–11 AM your
  local time) matter more than late ones.
- The hunter (whoever submits the product) gets attribution. If you
  hunt yourself, you must be the maker — PH is fine with that, but you
  forfeit the "external endorsement" signal. If you can convince
  someone with karma to hunt you, do it. Otherwise self-hunt.
- After 24h the post is frozen — you cannot edit the description.
  Triple-check before submitting.
